# Card Flip

A simple HTML and CSS project that creates a flip-card effect with a stylized card design.

## Preview

This project displays a card that flips on hover to reveal a back side with a home icon and card number.

## Features

- Hover-based 3D flip animation
- Clean card layout with front and back faces
- Fully responsive layout using CSS
- No JavaScript required

## Project Structure

- `index.html` — card markup
- `style.css` — styling and animation

## Run the Project

1. Open `index.html` in your browser, or
2. Use a live preview extension such as Live Server in VS Code.
